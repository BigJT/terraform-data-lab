## Step 5 - Convert JSON into resources
resource "terraform_data" "vm" {
    for_each = {
        for vm in local.vms :
        vm.name => vm
    }
    input = each.value
}

# Now let's make this more realistic

At the moment you have:

```
vm01
```

Let's turn it into:

```
vm01
vm02
vm03
vm04
vm05
```

with different properties.

Your `main.tf` becomes:

```hcl
locals {

  virtual_machines = {

    vm01 = {
      name        = "vm01"
      environment = "dev"
      os          = "linux"
      cpu         = 4
      memory      = 16
      ip          = "10.0.1.5"
    }

    vm02 = {
      name        = "vm02"
      environment = "prod"
      os          = "linux"
      cpu         = 8
      memory      = 32
      ip          = "10.0.2.5"
    }

    vm03 = {
      name        = "vm03"
      environment = "prod"
      os          = "windows"
      cpu         = 16
      memory      = 64
      ip          = "10.0.3.5"
    }

  }

}


resource "terraform_data" "vm" {

  for_each = local.virtual_machines

  input = each.value

}
```

Run:

```powershell
terraform apply
```

Then:

```powershell
terraform console
```

Now:

```terraform
terraform_data.vm
```

will give:

```text
{
 "vm01" = ...
 "vm02" = ...
 "vm03" = ...
}
```
